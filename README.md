# Save Sixes Rd

Redesign and rebuild of the Save Sixes Road community campaign website.

## Project status

This repository starts with the content and visual discovery phase. The public Squarespace site is the source of truth for existing copy, routes, images, blog posts, library materials, and campaign links. The new interface will be designed as a cleaner, more credible campaign site rather than a direct visual copy.

## Planned capabilities

- Public campaign website
- Blog and article publishing
- Library for documents, analysis, and images
- Petition and contact journeys
- Newsletter signup with double opt-in
- New-post email delivery
- Protected content administration
- Railway deployment with a custom domain
